# 🍰 Chiquitita – Boutique Pastry Shop

## Overview

**Chiquitita** is a modern boutique pastry shop website designed to showcase handcrafted desserts through an elegant and inviting digital experience.

The website combines artisanal baking, premium branding, and an intuitive shopping flow, allowing customers to discover products, learn the bakery's story, place orders, and contact the business effortlessly.
